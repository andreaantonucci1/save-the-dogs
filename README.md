# Save the dogs
A Scratch maze adventure game where you play as a bat, find keys, avoid ghosts, unlock doors, and rescue dogs across three levels.
## Play the game
[Play save the dogs on Scratch](https://scratch.mit.edu/projects/1380376276)
## Features
- 3 maze levels
- Keys and locked doors
- Dogs to rescue
- Sound effects and background music
- Victory screen
- Restart button
## Built with
Scratch
## What I learned
- Game logic
- Collision detection
- Broadcasts
- Level transitions
- Basic game design
